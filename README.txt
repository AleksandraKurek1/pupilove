PUPILOVE - SKLEP Z AKCESORIAMI DLA ZWIERZĄT

JAK URUCHOMIĆ
1. Rozpakuj plik ZIP.
2. Otwórz folder pupilove-sklep.
3. Kliknij dwukrotnie index.html albo otwórz go w przeglądarce.
4. Aby edytować projekt, otwórz folder w Visual Studio Code.

STRUKTURA
- index.html - strona główna
- o-nas.html - historia i misja marki
- oferta.html - produkty, filtry i warianty
- galeria.html - galeria zdjęć
- kontakt.html - formularz i dane sklepu
- zestaw-startowy.html - strona kampanii z zegarem i CTA
- koszyk.html - koszyk, ilości, warianty, rabat i podsumowanie
- style.css - style i układ responsywny
- script.js - produkty, koszyk i interakcje

FUNKCJE
- Dodawanie produktów do koszyka i zapamiętywanie ich w localStorage.
- Zmiana ilości, wariantów i usuwanie produktów.
- Filtry kategorii oraz sortowanie cen.
- Kod rabatowy WITAJ10 (10%).
- Bezpłatna dostawa od 150 zł, poniżej 150 zł dostawa kosztuje 14 zł.
- Formularz kontaktowy i przejście do kasy są demonstracyjne.
- Zdjęcia są pobierane z Unsplash, więc do ich wyświetlania potrzebne jest połączenie z internetem.

UWAGA
To projekt demonstracyjny, nie jest połączony z serwerem, płatnościami ani systemem realizacji zamówień.
